FurBaby Finds – Privacy Policy for the FurBaby Finds Pin Publisher

Last updated: November 2026

FurBaby Finds Pin Publisher is a private tool run by the owner of the FurBaby Finds Etsy shop (https://www.etsy.com/shop/FurBabyFindsUS). It publishes pins of the shop's own products to the shop's own Pinterest boards. It has one user: the shop owner. It is not offered to anyone else.

What it accesses

With the shop owner's permission, given through Pinterest's sign-in (OAuth), the tool reads the owner's Pinterest account name and board list, creates pins on the owner's boards, and reads those boards' pins to confirm that a pin was published. It does not access other Pinterest users' data, and it does not access the owner's followers, messages or analytics.

What it stores

The Pinterest access and refresh tokens, and a record of the pins it has published (pin ID, board, title and time). These are stored only on the shop owner's own computer. They are not uploaded to any server or shared with anyone.

What it does not do

It does not sell, rent or share any data. It does not use Pinterest data for advertising or profiling. It does not combine Pinterest data with other data sources.

Removing access

The shop owner can revoke the tool's access at any time in Pinterest under Settings, then Security and logins, then Apps. Revoking access stops all posting, and the stored tokens become useless.
